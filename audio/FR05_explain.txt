同学们好！今天我们来看一个超美的分形——Julia 集（Julia Set）。

Julia 集和曼德博集合是一对"孪生兄弟"——同样迭代 z = z² + c，但 c 是固定的，z 是变量。

曼德博集合：c 变化，z₀ = 0，问 c 让 z 不发散
Julia 集合：c 固定，z 任意，问哪些 z 不发散

经典 Julia 集：
- c = 0：z² = z²，所有 z 都发散（Julia 集是单位圆）
- c = -1：z² - 1，著名的"圣诞树"分形
- c = -0.8 + 0.156i：连通的 Julia 集（"海马"）
- c = 0.3 + 0.5i：连通但有 dendrite（树枝状）
- c = i：连通
- c = -0.4 + 0.6i：连通的"双螺旋"
- |c| > 2：所有 z 都逃逸，Julia 集 = ∞（空集）
- |c| = 2 附近：复杂的边界

Julia 集的关键定理（Fatou 和 Julia，1918-1920）：
- Julia 集连通 ↔ 0 在曼德博集合里
- Julia 集不连通（康托尔尘）↔ 0 不在曼德博集合里

具体说：
- c = 0：0 在 M 内（z=0 永远 0），但 Julia 集 = 单位圆
- c = 0.25：0 在 M 内，Julia 集 = 简单环
- c = -0.8 + 0.156i：0 在 M 内，Julia 集 = 复杂的连通分形
- c = -0.5 + 0.5i：0 在 M 边界附近，Julia 集 = 树枝状（连通）
- c = -1：0 在 M 边界附近，Julia 集 = "圣诞树"分形

举例：c = -0.8 + 0.156i 的 Julia 集
- 看起来像连通的"海马"形分形
- 放大看有无限细节
- 自相似，每个区域都"长"得跟整体像

举例：c = -0.4 + 0.6i 的 Julia 集
- 连通的双螺旋
- 看起来像两条相互缠绕的螺旋

举例：c = i 的 Julia 集
- 简单的椭圆

举例：c = -1 的 Julia 集
- 圣诞树（无限自相似）
- 颜色：黑色在集合内，彩色在集合外（迭代次数决定颜色）

Julia 集的"美"：每个 c 都对应一个独特的分形。改变 c 的小数点后几位，整个分形完全改变。

应用：
- 复分析
- 动力系统
- 混沌理论
- 艺术生成

计算机生成 Julia 集：
1. 屏幕每个像素 = 复数 z
2. 迭代 z² + c
3. 迭代 1000 步
4. 如果 |z| 一直 < 2：黑色（在集合内）
5. 如果逃逸：用逃逸迭代次数着色

Julia 集 vs 曼德博集合：
- 曼德博：参数空间，c 变化，z₀ = 0
- Julia：状态空间，c 固定，z 变化
- 每个 c 对应一个 Julia 集
- 曼德博集合的每个 c"控制"一个 Julia 集

现在请同学们自己动手：点"Julia 集"，看 c = -0.8 + 0.156i 的"海马"分形。试 c = -0.4 + 0.6i 的"双螺旋"。试 c = -1 的"圣诞树"。明天带过来我们比一比。

记住：数学不只藏在书本里——藏在每一个"复数迭代"的有趣分形里。
