同学们好！今天我们来看一个超美的极限——(1 + 1/n) 的 n 次方趋近 e。

什么是这个极限？
- n 等于 1：(1+1)¹ = 2
- n 等于 2：(1+0.5)² = 2.25
- n 等于 5：(1+0.2)⁵ ≈ 2.488
- n 等于 10：(1+0.1)¹⁰ ≈ 2.594
- n 等于 100：(1+0.01)¹⁰⁰ ≈ 2.7048
- n 等于 1000：(1+0.001)¹⁰⁰⁰ ≈ 2.7169
- n 等于 10000：(1+0.0001)¹⁰⁰⁰⁰ ≈ 2.7181
- n 等于 100000：(1+0.00001)¹⁰⁰⁰⁰⁰ ≈ 2.71827
- n 趋近无穷：e = 2.7182818...

这就是 e 的定义之一！也称"连续复利"。

为什么叫"连续复利"？
- 银行年利率 100%
- 如果每年结算一次：本金 2 元（涨 100%）
- 每半年结算一次：(1+0.5)² = 2.25
- 每季度：(1+0.25)⁴ ≈ 2.441
- 每月：(1+1/12)¹² ≈ 2.613
- 每周：(1+1/52)⁵² ≈ 2.693
- 每天：(1+1/365)³⁶⁵ ≈ 2.7146
- 每秒：(1+1/31536000)³¹⁵³⁶⁰⁰⁰ ≈ 2.7182
- 连续复利：e ≈ 2.71828

所以"连续复利"就是 e！

这个结果来自 17 世纪。Jacob Bernoulli 在 1683 年研究复利问题时首先注意到这个极限。

数学家后来发现：
- (1 + 1/n)^n 严格递增趋近 e
- (1 + 1/n)^(n+1) 严格递减趋近 e
- 收敛速度：误差约 1/(2n)

e 是无理数（连分数形式 2; 1, 2, 1, 1, 4, 1, 1, 6, ... 很有规律）和超越数。

应用：
- 金融：连续复利、期权定价（Black-Scholes）
- 物理：衰变常数、增长率
- 概率：泊松过程
- 信息论：自然对数
