同学们好！今天我们来看一个超有趣的概率问题——3 个杯子猜球（贝叶斯思维）。

游戏：3 个杯子扣着，1 个杯子里有球。你看不见球在哪。主持人（知道球在哪）给你一个提示——指向一个空杯子说"这个没有"。

问：剩下的 2 个杯子里，球更可能在哪个？

直觉：1/2 vs 1/2。

但答案是：被主持人指向的"空杯子"被排除了，剩下 2 个杯子的概率分别是 1/3 和 2/3——其中一个概率是另一个的 2 倍！

详细分析：
- 选你最开始猜的杯子
- 主持人（知道球在哪）开一个**空的**杯子
- 你的选择 A 不变，主持人排除 B，剩下的 C 的概率

贝叶斯分析：
- 先验：球在 A、B、C 各 1/3
- 主持人开 B（说"这个空"）后：
  - P(球在 A | 主持人开 B) = 1/3
  - P(球在 B | 主持人开 B) = 0
  - P(球在 C | 主持人开 B) = 2/3

为什么 C 是 2/3？因为主持人"在 B 和 C 中开 B"——B 和 C 加起来原本是 2/3 概率（不在 A），但 B 现在是 0，所以全部 2/3 转移到 C。

但如果主持人是从 3 个中**随机**开一个空的，结果就不同：
- 主持人有 1/3 概率开 A（如果 A 空），但 A 是你的选择，主持人不能开你的选择
- 主持人有 2/3 概率开一个空杯子
- 如果开 B：P(球在 A | 开 B) = 1/3, P(球在 C | 开 B) = 2/3
- 如果开 C：P(球在 A | 开 C) = 1/3, P(球在 B | 开 C) = 2/3

平均：P(球在 A) = 1/3, P(球在 B 或 C) = 1/3 + 1/3 = 2/3。

但 3 门问题里主持人是"知道球在哪"的主持人，不是随机的。所以 C 的概率还是 2/3。

具体类比 3 门问题：
- 3 门：1 门有奖，2 门空。你选 1 门。主持人开 1 空门。换门胜率 2/3。
- 3 杯：1 杯有球，2 杯空。你选 1 杯。主持人开 1 空杯。换杯胜率 2/3。

完全等价。

主持人开空杯的"信息量"是关键：他把 2/3 的概率压缩到 1 个选项上。

应用：
- 医学检测（贝叶斯定理）
- 搜索算法（信息更新）
- 决策理论
- 机器学习（朴素贝叶斯）

主持人"知道答案"还是"随机"——这是核心区别。

随机主持人的例子：
3 个门，1 个有奖。你选 1 个。主持人从剩下 2 个中随机开一个，假设开的是空门。换门胜率 1/2（无优势）。但如果主持人一定开空门（知道答案），换门胜率 2/3。

3 杯游戏的启示：
- 信息更新 = 概率重新分配
- 主持人知道答案 → 选主持人没指的更可能
- 主持人随机 → 选剩下的没区别

现在请同学们自己动手：点"3 杯猜球"，玩 100 次，记录你换杯的胜率。看是不是 2/3 胜？试试"随机主持人"模式，看胜率是不是 1/2？明天带过来我们比一比。

记住：数学不只藏在书本里——藏在每一个"主持人有信息"的有趣概率里。
