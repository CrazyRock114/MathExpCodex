同学们好！今天我们来看一个超实用的概率分布——泊松分布（Poisson）。

泊松分布：在固定时间/空间内，稀有事件发生次数 X 的分布。

P(X = k) = λᵏ × e⁻λ / k!

其中 λ 是单位时间内平均发生次数。

泊松分布的均值 = λ
泊松分布的方差 = λ
泊松分布的标准差 = √λ

举个例子：某路口平均每小时 5 辆车通过，X 是 1 小时内通过的车数。
- P(X = 0) = 5⁰ × e⁻⁵ / 0! = e⁻⁵ ≈ 0.67%
- P(X = 1) = 5¹ × e⁻⁵ / 1! ≈ 3.37%
- P(X = 2) = 5² × e⁻⁵ / 2! ≈ 8.42%
- P(X = 3) ≈ 14.04%
- P(X = 5) ≈ 17.55%（峰值）
- P(X = 10) ≈ 1.83%
- P(X = 20) ≈ 0.00000058

均值 = 5，方差 = 5，标准差 = √5 ≈ 2.24。

泊松分布的特征：
- 离散、非负、稀疏事件
- λ 越大越接近正态分布
- λ 小时高度偏斜
- 满足"无记忆"和"稀疏独立"

泊松分布 vs 二项分布：当 n 很大、p 很小（np = λ 不大不小）时，二项分布 ≈ 泊松分布。

举例：10000 件产品，缺陷率 0.001，期望缺陷数 = 10。X ~ Bin(10000, 0.001) ≈ Poi(10)。

泊松过程：
- 满足"独立增量"的随机过程
- 在不相交时间区间上事件数独立
- 时间区间长度 t 内的计数 X ~ Poi(λt)

应用：
第一条：医院急诊室每小时病人数
第二条：路口每小时车流量
第三条：保险理赔数
第四条：网站访问数（每秒）
第五条：地震（每年某震级次数）
第六条：放射性衰变
第七条：电话呼入
第八条：粒子碰撞

泊松过程的特性：事件间的等待时间服从指数分布（指数分布的"无记忆性"意味着泊松过程的"无后效性"）。

应用举例：10000 件产品，1% 缺陷率。X ~ Bin(10000, 0.01) ≈ Poi(100)。P(X = 100) = 100¹⁰⁰ × e⁻¹⁰⁰ / 100! ≈ 0.04。

现在请同学们自己动手：点"泊松分布"，输入 λ，比如 1、5、10、20。看 P(X=0)、P(X=1)...看峰值。试试 λ=1 偏斜、λ=20 接近正态。明天带过来我们比一比。

记住：数学不只藏在书本里——藏在每一个"稀有事件计数"的有趣分布里。
