# 音频与文字稿边界

当前运行时不从源码仓库提供 MP3。旧版页面继续展示讲解文字稿，并明确提示音频二进制未随源码分发，避免把不存在的文件呈现为可播放或可下载资源。

- `*_explain.txt`、分阶段 `*.txt` 和 `scripts_v13/` 是历史文字稿，仍供内容审校与追溯使用。
- `v13_partial/` 中的 6 个 MP3 是不完整的历史样本，不属于生产媒体；它们的大小和 SHA-256 已记录在 `docs/ASSET_INVENTORY.md`。
- 在对象存储位置、许可、缓存策略和恢复演练确定前，不删除这 6 个样本，也不新增二进制音频。
- 将来若恢复音频，必须通过受管清单提供真实 URL，并为缺失、加载失败和文字稿回退编写测试。

运行 `npm run audit:assets` 可检查历史入口是否重新膨胀、运行时是否误声明音频，以及归档二进制是否仍局限在 `v13_partial/`。
