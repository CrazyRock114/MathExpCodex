同学们好！今天我们来看一个超级重要的代数恒等式——二项式定理。

什么是二项式？两项的和，比如 x + y。

二项式定理：
(x + y)ⁿ = Σ [C(n, k) × xᵏ × yⁿ⁻ᵏ]
其中 k 从 0 到 n。

C(n, k) = n! / (k! × (n-k)!) 是"二项式系数"——从 n 个里选 k 个的方法数。

举个例子：
(x + y)⁰ = 1
(x + y)¹ = x + y
(x + y)² = x² + 2xy + y²
(x + y)³ = x³ + 3x²y + 3xy² + y³
(x + y)⁴ = x⁴ + 4x³y + 6x²y² + 4xy³ + y⁴
(x + y)⁵ = x⁵ + 5x⁴y + 10x³y² + 10x²y³ + 5xy⁴ + y⁵

系数是：1 1、1 2 1、1 3 3 1、1 4 6 4 1、1 5 10 10 5 1——这正是帕斯卡三角！

二项式定理的历史：
- 中国杨辉 1261 年发现
- 中亚 al-Karaji 11 世纪发现
- 欧洲 Pascal 1654 年重新发现

二项式定理的应用：
- 概率：二项分布（n 次独立试验成功 k 次的概率 = C(n,k) pᵏ (1-p)ⁿ⁻ᵏ）
- 组合学：组合数公式
- 物理学：泰勒展开（二项式的极限）
- 信息论：熵的展开

特例：
- x = 1, y = 1：2ⁿ = Σ C(n, k)
- x = 1, y = -1：0 = Σ (-1)ᵏ C(n, k)（交错求和 = 0）
- x = y = 1：和上面一样
- 1 = (x+y)ⁿ / (x+y)ⁿ = Σ C(n, k) xᵏ yⁿ⁻ᵏ / (x+y)ⁿ

多项式定理（二项式推广）：
(x₁ + x₂ + ... + xₘ)ⁿ = Σ [(n! / (k₁! k₂! ... kₘ!)) × x₁ᵏ¹ x₂ᵏ² ... xₘᵏᵐ]
其中 k₁ + k₂ + ... + kₘ = n。

现在请同学们自己动手：点"二项式展开"，输入 (x+y) 的 n 比如 n=5。验证系数是 1 5 10 10 5 1。试试 (x+y)^6、(x+y)^7。看看 (x+1)^10 展开是什么？明天带过来我们比一比。

记住：数学不只藏在书本里——藏在每一个"两项之和的 n 次方"的有趣展开式里。
