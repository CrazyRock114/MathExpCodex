同学们好!今天我们来讲数学史上最浪漫、最戏剧性的故事——费马大定理的证明。
这个证明,跨越了 358 年,几代数学家接力,最终在 一九九五年由英国数学家安德鲁·怀尔斯完成。

先讲一个生活里的小故事。
你有没有玩过积木?
你有一堆积木,每一块上写着一个正整数。
现在问你:能不能找出三块积木,比如 a、b、c,使得 a 的 n 次方 + b 的 n 次方 = c 的 n 次方?
如果 n 等于 2,那太容易了——3、4、5 就是一组:3² + 4² = 9 + 16 = 25 = 5²。
3-4-5 这组勾股数,古代中国人早就知道了。
但如果 n 等于 3 呢?a³ + b³ = c³,有没有正整数解?
试试 1³ + 2³ = 1 + 8 = 9,不是立方数;3³ + 4³ = 27 + 64 = 91,不是立方数。
事实上,数学家证明:n 等于 3 时,没有正整数解。
n 等于 5、n 等于 7……都"看起来"没有解。
n 大于 2 时,真的没有解吗?
这就是费马大定理——也叫"费马最后定理",因为它是费马提出的所有猜想中最后一个被证明的。

还有一个更有趣的比喻。
想象你走进一家咖啡店,点了一杯"费马大定理"咖啡。
店员说:"对不起,这杯咖啡 358 年才煮得完。"
你问:"为什么这么慢?"
店员说:"因为这杯咖啡,要所有数学家一起煮。"
358 年,几百位数学家接力,每个人只负责加一点"料"——最终,怀尔斯完成了最后一步。

第二步,什么是费马大定理?
一六三七年,法国图卢兹有一位律师,名叫皮埃尔·德·费马。
他有一个特别的爱好——在数学书空白处写笔记。
一天,他在读古希腊数学家丢番图的《算术》时,在第八卷一个问题旁边的空白处写下了一段话:
"要将一个立方数分成两个立方数之和,或一个四次幂分成两个四次幂之和,或者一般地将一个高于二次的幂分成两个同次幂之和,这是不可能的。我确信已经发现了一种绝妙的证明,但页边太窄,写不下。"
用现代数学语言说就是:当 n 大于 2 时,方程 x 的 n 次方 + y 的 n 次方 = z 的 n 次方,没有正整数解。
费马是不是真证明了呢?很可能他只是"以为"自己证明出来了。
因为他死后,人们在他所有手稿里都没找到那个"绝妙的证明"。
这成了数学史上最大的"坑"——一个随手写下的猜想,358 年后才被解决。

第三步,我们动手算算小情形。
n 等于 3:有没有正整数 a、b、c,使得 a³ + b³ = c³?
数学家欧拉在 一七七〇年证明:没有。这是费马大定理第一个被证出的情形。
n 等于 4:欧拉也证明了。
n 等于 5:一八二五年,狄利克雷和勒让德独立证明。
n 等于 7:也是 19 世纪数学家证明的。
到了 19 世纪中叶,数学家们已经能处理"某些特殊的 n"。
但"一般的 n",还是毫无头绪。
一八五七年,德国数学家库默尔用"理想数"做出部分突破——他证明了对一大类 n,费马大定理成立。
"理想数"是库默尔发明的一个巧妙工具,能把"除法"在某些情形下变干净。
但"部分"不等于"全部",还有一类 n(叫做"正则素数")没解决。
对"非正则素数",库默尔的方法失效。
所以整个 19 世纪,费马大定理只能算"部分解决"。
数学家们用各种巧妙工具——从初等到高深,一个个突破;
但"任意 n"始终像一道高墙,挡住所有人的去路。

第四步,深入观察为什么 358 年这么难。
为什么一道看起来简单的题,会难住人类 358 年?
因为它"伪装"得很深。
表面上,费马大定理是关于整数解的问题;
但实际上,要用到非常高深的数学——代数几何、模形式、伽罗瓦表示,等等。
"代数几何"研究多项式方程的图像,跟几何学结合;
"伽罗瓦表示"是把"对称性"用矩阵描述。
任何一个时代的数学家,如果工具不够,都解决不了。
古代数学家只能处理小情形;近代数学家有群论、复数;现代数学家还要用到 20 世纪发展的代数几何和模形式。
真正的转机出现在 一九八四年。
德国数学家格哈德·弗赖提出一个天才想法:
如果费马方程有解,那就能构造一条"非常怪异"的椭圆曲线。
"椭圆曲线"是数学里一种特殊曲线,长得很像被压扁的圆。
"非常怪异"是说不满足一个叫做"模性"的性质。
一九九〇年,美国数学家里贝特证明:只要 Taniyama-Shimura 猜想成立,那条"怪异"曲线就根本不可能是"模的"。
"模性"是椭圆曲线的一个"身份证"——满足这个性质的椭圆曲线,跟"模形式"有对应关系。
"模形式"是数学里一种高度对称的函数。
这意味着:如果 Taniyama-Shimura 猜想对,那费马大定理就对!
剩下的关键一步,就是证明 Taniyama-Shimura 猜想。

第五步,历史的接力棒。
一六三七年,费马写下猜想。
一七七〇年,欧拉证明 n=3。
一八二五年,狄利克雷和勒让德证明 n=5。
一八五七年,库默尔"理想数"部分突破。
一九八四年,弗赖提出"怪异椭圆曲线"想法。
一九九〇年,里贝特证明关键联系。
一九九三年 6 月 23 日,英国数学家安德鲁·怀尔斯在剑桥大学宣布——他证明了"半稳定情形"下的 Taniyama-Shimura 猜想,从而证明了费马大定理!
全世界媒体蜂拥而至,《纽约时报》头版报道。
但审稿过程中发现了一处致命漏洞!怀尔斯陷入了长达一年的绝望。
一九九四年 9 月,他突然想到可以用他的学生理查德·泰勒的一个方法来修补。
一九九四年 10 月,他终于在书房里补好了最后一环——凌晨时刻,与泰勒共同署名。
一九九五年 5 月,完整论文发表在《数学年刊》上,共 109 页。
一九九六年 3 月,怀尔斯获沃尔夫奖;一九九七年 6 月获沃尔夫斯凯尔十万马克悬赏大奖——这正是 一九〇八年那位"被数学救了一命"的德国实业家设的奖。

怀尔斯是何许人也?
他 一九五三年出生于英国剑桥,小时候就迷恋费马大定理。
10 岁那年,他在图书馆看到费马大定理的故事,从此立志要解决它。
他在牛津大学读本科,在剑桥大学读博士。
博士毕业后,他到美国普林斯顿大学任教,在相对"安静"的环境里默默研究 7 年。
最终他用了 7 年秘密研究,加上 1 年修补漏洞,完成了 358 年的接力。
他说:"这是我童年时代的梦想,实现它是我一生中最自豪的时刻。"
注意,怀尔斯研究费马大定理是"秘密进行的"——他怕一旦公开,会跟其他数学家竞争,反而打乱自己的节奏。
直到 一九九三年公开宣布前,全世界只有他自己知道他在做这件事。

给同学们的话:费马大定理的证明告诉我们——
数学需要耐心、需要天才、更需要"最后一公里的坚持"。
358 年的接力,每一个数学家都贡献了一小步。
同学们,自己动手试试看:用 Python 写代码,搜索 n 等于 3、4、5 时,方程 a 的 n 次方 + b 的 n 次方 = c 的 n 次方 是否有正整数解;
你会发现,搜遍 1 到 1000,都找不到解——这就是费马大定理的"经验证据"。
动手试一试,你会亲身体验到:有些问题,即使搜不到解,也不一定不存在。
这就是数学的魅力:它不止于"试试看",还要"证明"。
数学家用 358 年告诉你:"试试看"不够,必须"证明对"。

费马大定理的故事告诉我们:
有些猜想,看起来简单,做起来要一辈子;
有些成就,看起来是一瞬间,背后是几十年的积累;
有些接力,看起来是某一个人,其实是几代人的合作。
怀尔斯站在巨人的肩膀上——欧拉、狄利克雷、库默尔、弗赖、里贝特……
每个人都是巨人,每个人都是接力手。
