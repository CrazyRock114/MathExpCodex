同学们好！今天我们来看一个超神秘但不出名的常数——欧拉-马斯刻若尼常数 γ。

什么是 γ？它等于调和级数减去自然对数的极限：
γ = lim (n→∞) [1 + 1/2 + 1/3 + ... + 1/n - ln n]

γ 约等于 0.5772156649...

为什么这么定义？因为调和级数 1 + 1/2 + 1/3 + ... 发散到无穷（虽然发散很慢）。但它减去 ln n 后趋近一个常数 γ。

我们算几项：
- n=1：1 - 0 = 1
- n=2：1 + 0.5 - 0.693 = 0.807
- n=3：1 + 0.5 + 0.333 - 1.099 = 0.735
- n=10：1 + 0.5 + 0.333 + ... + 0.1 - 2.303 = 0.668
- n=100：约 0.588
- n=1000：约 0.577
- n=10000：约 0.5772
- n=100000：约 0.57721

n 越大越接近 0.57721...，但收敛很慢！

γ 是欧拉在 1735 年研究调和级数时引入的。马斯刻若尼在 1790 年独立计算了更多位数。

γ 的性质：
- γ 是无理数（已证明）
- γ 是超越数？还没证明
- 不知道 γ 是不是有理数
- γ 跟 ζ 函数（zeta 函数）有关：γ = lim (s→1) [ζ(s) - 1/(s-1)]

γ 跟很多数学问题有关：
- 黎曼猜想：如果 ζ(s) = 0，那 Re(s) 等于 1/2。γ 跟 ζ(1) 有关
- 调和级数的发散速度
- Γ 函数（伽马函数）的欧拉反射公式

数学家们至今不知道 γ 是不是有理数！

γ 跟日常生活无关，但跟数学的很多"极限问题"有关。

应用：
- 数论：素数倒数和（ln ln n + γ + ...）
- 概率论：随机过程的极限
- 物理学：量子力学中的某些极限
