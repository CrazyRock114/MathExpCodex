同学们好！今天我们来看一个超基础但超重要的问题——怎么判断一个数是不是三角形数。

什么是三角形数？T_n = n 乘 (n+1) 除以 2。前 10 个：1、3、6、10、15、21、28、36、45、55。

问题来了：给定 N，怎么知道 N 是不是三角形数？如果是，怎么求对应的 n？

直接解方程：T_n = n(n+1)/2 = N
=> n² + n - 2N = 0
=> n = (-1 + √(1 + 8N)) / 2

所以判断方法：
- 计算 8N + 1
- 看 8N + 1 是不是完全平方数（开方后是整数）
- 如果是，n = (√(8N+1) - 1) / 2 就是答案

举个例子：N = 15。8 乘 15 + 1 = 121 = 11²。n = (11 - 1) / 2 = 5。验证 T_5 = 15。✓
N = 16。8 乘 16 + 1 = 129。不是完全平方数（11²=121, 12²=144）。所以 16 不是三角形数。✓
N = 21。8 乘 21 + 1 = 169 = 13²。n = (13 - 1) / 2 = 6。T_6 = 21。✓

这个判断方法对所有 N 都成立。

另一个方法：直接循环找 n，n = 1, 2, 3, ..., 直到 T_n >= N。如果 T_n = N 就是三角形数，否则不是。

三角形数还有几个超级有用的性质：

第一条：T_{a+b} = T_a + T_b + a×b。比如 T_7 = T_3 + T_4 + 3×4 = 6 + 10 + 12 = 28。✓

第二条：T_{n+1} - T_n = n+1。相邻三角形数差递增。

第三条：每个自然数 n 都能写成最多 3 个三角形数之和（已被高斯证明）。

第四条：平方数 8N + 1 是判断"是否三角形数"的关键。

现在请同学们自己动手：点"判断三角形数"，输入一个数比如 45、55、66。验证 45 = T_9、55 = T_10。66 是不是？8×66+1=529=23²，所以是！n = (23-1)/2 = 11。验证 T_11 = 11×12/2 = 66。✓ 明天带过来我们比一比。

记住：数学不只藏在书本里——藏在每一个"用公式判断"的有趣技巧里。
