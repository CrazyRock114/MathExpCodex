同学们好！今天我们来看一个超经典的游戏——井字棋（Tic-Tac-Toe）。

井字棋：3×3 网格，玩家 X 和 O 轮流画。先连成 3 个（横、竖、斜）的人赢。9 格都填满还没人赢就是平局。

井字棋的解空间：
- 9! = 362880 种游戏序列
- 但旋转、镜像视为相同后约 255168 种
- 去除非法序列（提前结束）：255168 - 46080 = 209088

井字棋的最优策略：用极小化极大（minimax）算法或简化版（看自己能不能赢 → 看对手能不能赢 → 选角或中心）。

井字棋的结果（双方都最优）：
- X（先手）必不输
- 如果 X 下中心，O 不可能赢
- 如果 X 下角，O 也不赢
- 所以最优情况下永远是平局

井字棋 AI 难度：
- 简单：随机
- 中等：看能不能赢或挡
- 困难：极小化极大（必平）

极小化极大算法：
- 假设双方都下最优
- 评分：赢 = +10、输 = -10、平 = 0
- 自己回合选最大分，对方回合假设选最小分
- 递归到所有可能

井字棋的状态数：
- 9 格：2⁹ = 512 种状态（每格空、X、O）
- 但去掉不可能状态：实际 5478 种
- 加旋转/镜像：约 765 种本质不同

井字棋的"必平"定理：
- 先手 X 必不输
- 双方都最优 = 平局

井字棋 AI 极小化极大（伪代码）：
function minimax(board, depth, isMax):
  if X wins: return 10 - depth
  if O wins: return depth - 10
  if no empty: return 0
  if isMax:
    best = -∞
    for each empty cell:
      board[i] = X
      score = minimax(board, depth+1, false)
      board[i] = empty
      best = max(best, score)
    return best
  else:
    best = +∞
    for each empty cell:
      board[i] = O
      score = minimax(board, depth+1, true)
      board[i] = empty
      best = min(best, score)
    return best

井字棋的"陷阱"——人能赢 AI 吗？
- AI 用极小化极大：必平
- AI 用简单策略：人可能赢
- AI 随机：人 60% 胜率

应用：
- 极小化极大算法教学
- 博弈论入门
- AI 算法基础

井字棋的扩展：
- m×n 井字棋（连 k 个）
- 5×5 井字棋
- 3D 井字棋（4×4×4）

井字棋的"先手必平"是著名的"算法正确性"例子。

井字棋变种：
- 终极井字棋（Ultimate Tic-Tac-Toe）：9×9 大网格分 9 个 3×3
- 3D 井字棋
- 五子棋（连 5 个）
