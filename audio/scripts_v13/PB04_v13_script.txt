同学们好！今天我们来看一个超实用的分布——几何分布。

什么是几何分布？独立伯努利试验（每次成功概率 p），首次成功需要的试验次数 X 的分布。

P(X = k) = (1-p)ᵏ⁻¹ × p

几何分布的均值：E[X] = 1/p
几何分布的方差：Var(X) = (1-p)/p²
几何分布的标准差：σ = √(1-p)/p

举个例子：抛硬币直到正面，p = 0.5。
- P(X=1) = 0.5（第一次就正面）
- P(X=2) = 0.5 × 0.5 = 0.25（第一次反面、第二次正面）
- P(X=3) = 0.5² × 0.5 = 0.125
- P(X=k) = (0.5)ᵏ

均值 = 1/0.5 = 2（平均要 2 次才出正面）。
方差 = 0.5/0.25 = 2，标准差 = √2 ≈ 1.41。

几何分布有一个特殊性质——"无记忆性"：
P(X > m + n | X > m) = P(X > n)

意思是"已经等了 m 次还没成功，再等 n 次才成功的概率 = 第一次等 n 次才成功的概率"。

举例：抛硬币 5 次都没正面，再抛 5 次的分布 = 重新开始抛 5 次的分布。无记忆！

这个性质让几何分布在工程中很有用——比如设备故障、维修等待、顾客到达时间建模。

几何分布的应用：
- 设备故障：首次故障时间
- 顾客到达：下次顾客到达时间
- 股票价格：首次突破某价格的时间
- 抽奖：首次中奖次数
- 找硬币正面：抛几次才出正面
- 产品出货：第一次质检通过需要几次

几何分布 vs 负二项分布：几何分布是"首次成功需要几次"，负二项分布是"第 r 次成功需要几次"。

举例：抛硬币直到第 3 次正面，需要的次数 X ~ 负二项分布。X 可以是 3、4、5、6、7...。

几何分布的累积分布：F(k) = P(X ≤ k) = 1 - (1-p)ᵏ。

举例：p=0.1, k=10。F(10) = 1 - 0.9¹⁰ = 1 - 0.349 = 0.651。所以 10 次内首次成功的概率是 65.1%。

记住：数学不只藏在书本里——藏在每一个"首次成功需要多久"的有趣等待里。

最后总结，这 几何分布（首次成功） 我们讲了 5 步：几何分布：首次成功 → 算分布 → 扫描 k → 期望与无记忆性 → 几何分布小史。
