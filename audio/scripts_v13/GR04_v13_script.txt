同学们好！今天我们来看一个超基础但超有用的数据结构——二叉树遍历。

什么是二叉树？每个节点最多 2 个子节点的树形结构。

什么是遍历？访问树中每个节点恰好一次。

二叉树有 3 种遍历方式：

第一种：先序遍历（Pre-order）
顺序：根 → 左 → 右
"先访问根，再访问左子树，再访问右子树"

第二种：中序遍历（In-order）
顺序：左 → 根 → 右
"先访问左子树，再访问根，再访问右子树"

第三种：后序遍历（Post-order）
顺序：左 → 右 → 根
"先访问左子树，再访问右子树，再访问根"

举个例子：树根 A，左子 B（B 的左子是 D、右子是 E），右子 C（C 的左子是 F、右子是 G）。

先序：A → B → D → E → C → F → G
中序：D → B → E → A → F → C → G
后序：D → E → B → F → G → C → A

3 种遍历方式刚好相反。

二叉树遍历的应用：
- 先序：复制一棵树、序列化
- 中序：二叉搜索树（BST）按升序输出节点
- 后序：删除一棵树、计算表达式（后缀表达式）

为什么中序遍历 BST 能按升序输出？因为 BST 满足"左子 < 根 < 右子"。中序访问时，左子都先于根、右子都后于根，所以是升序。

举例：BST
    5
   / \
  3   7
 / \ / \
2  4 6  8

中序：2 → 3 → 4 → 5 → 6 → 7 → 8（升序！）

遍历的递归实现（伪代码）：
- 先序：visit(node); preorder(node.left); preorder(node.right)
- 中序：inorder(node.left); visit(node); inorder(node.right)
- 后序：postorder(node.left); postorder(node.right); visit(node)

Morris 遍历：不用递归也不用栈，O(1) 空间——很巧妙但难理解。

迭代版：用显式栈模拟递归。
