同学们好！今天我们来看一个超实用超快的排序算法——快速排序（Quick Sort）。

快速排序：分治算法。选一个 pivot（基准），把数组分成"小于 pivot"和"大于 pivot"两部分，递归。

算法步骤：
1. 选 pivot（基准元素）
2. Partition：把数组分成小于 pivot 和大于 pivot 两部分
3. 递归排序两部分

举例：[5, 2, 8, 1, 9, 3]，选 pivot = 5
Partition：小于 5 的 [2, 1, 3]、pivot 5、大于 5 的 [8, 9]
递归 [2, 1, 3]：选 pivot = 2，[1]、2、[3]
递归 [8, 9]：选 pivot = 8，[8]、[9]
结果：[1, 2, 3, 5, 8, 9] ✓

时间复杂度：
- 最坏：O(n²)（pivot 选得不好，每次只能分一个元素）
- 平均：O(n log n)
- 最好：O(n log n)
- 空间：O(log n)（递归栈）

pivot 选择策略：
第一条：固定选第一个或最后一个
第二条：随机选
第三条：三数取中（首、中、尾的中位数）
第四条：九数取中（更稳）

Lomuto Partition：
- pivot 选最后
- 双指针：i = -1, j 从 0 到 n-1
- arr[j] < pivot 时 i++，swap arr[i] 和 arr[j]
- 最后 swap arr[i+1] 和 pivot

Hoare Partition：
- pivot 选第一个
- 双指针：i 从左、j 从右
- 找 arr[i] ≥ pivot、arr[j] ≤ pivot 的位置
- swap，缩小范围
- 继续到 i ≥ j

Hoare 比 Lomuto 快（少 swap），但需要小心边界。

快速排序的优化：
第一条：小数组（n < 16）用插入排序
第二条：median-of-three pivot 选择
第三条：三路快排（处理重复元素）
第四条：迭代代替递归
第五条：尾递归优化

快排是不稳定的（相等元素相对位置可能变）。

快速排序的发明：1962 年 Tony Hoare 提出。至今仍是最快的通用排序算法。

应用：
- C 标准库 qsort
- Unix sort 命令
- 编程语言内置排序
- 数据库索引

快排 vs 归并排序：
- 快排：平均 O(n log n)，最坏 O(n²)，空间 O(log n)，不稳定
- 归并：永远 O(n log n)，空间 O(n)，稳定
- 选哪个？看稳定性需求和最坏情况容忍度

Tim 排序（Python/Java 用）：归并 + 插入，处理真实数据的"局部有序"。

举例：100 万个数字排序。
- 快排：100 万 × log(100 万) ≈ 2000 万次比较
- 冒泡：100 万² = 1 万亿次比较
- 加速 5 万倍！
