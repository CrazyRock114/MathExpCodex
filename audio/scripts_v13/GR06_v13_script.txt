同学们好！今天我们来看一个超重要但超简单的原理——容斥原理。

容斥原理：把多个集合的并集的大小，用它们单独的大小和交集来表示。

最简单的版本（2 个集合）：
|A ∪ B| = |A| + |B| - |A ∩ B|

为什么减一次？因为 |A| + |B| 把 A∩B 加了两次，要减去一次。

3 个集合：
|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|

加减规律："奇数加，偶数减"。

n 个集合：
|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| - Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| - ... + (-1)ⁿ⁺¹ |A₁ ∩ A₂ ∩ ... ∩ Aₙ|

举例：1 到 100 中，能被 2 整除或能被 3 整除的数有几个？
- A = {能被 2 整除}：50 个
- B = {能被 3 整除}：33 个
- A ∩ B = {能被 6 整除}：16 个
- |A ∪ B| = 50 + 33 - 16 = 67 个

验证：100 以内 67 个数能被 2 或 3 整除。

举例：1 到 100 中，能被 2、3、5 之一整除的数有几个？
- A = {能被 2 整除}：50
- B = {能被 3 整除}：33
- C = {能被 5 整除}：20
- A ∩ B = {能被 6 整除}：16
- A ∩ C = {能被 10 整除}：10
- B ∩ C = {能被 15 整除}：6
- A ∩ B ∩ C = {能被 30 整除}：3
- |A ∪ B ∪ C| = 50 + 33 + 20 - 16 - 10 - 6 + 3 = 74

容斥原理的应用：
- 计数：满足某些条件的数有几个
- 概率：满足某些事件的事件概率
- 数论：欧拉 φ 函数
- 组合学：错排公式
- 容错：集合的"所有不满足"

容斥原理是 19 世纪英国数学家 Sylvester 和 Poincaré 推广的。

经典例子："错排"问题（之前讲过）就是用容斥原理算的：n 个元素的错排数 = n! × Σ (-1)ᵏ/k!。

欧拉 φ 函数：φ(n) 等于 1 到 n 中跟 n 互素的数的个数，可以用容斥原理从 n 中减去能被 n 的素因子整除的数。
