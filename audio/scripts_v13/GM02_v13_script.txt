同学们好！今天我们来看一个超简单的几何事实——多边形外角和恒等于 360°。

什么是外角？多边形每个顶点处，外部的"凸出"角。比如三角形每个顶点处的外角。

外角 + 内角 = 180°（因为它们组成一条直线）。

任意凸多边形（每条边都向外凸），外角之和恒等于 360°！

这个定理最早由欧几里得在 2000 多年前证明。看起来简单，但应用超级广泛。

为什么外角和恒等于 360°？
方法一：把多边形每个顶点处的"外角"想象成"你沿着多边形走一圈，每走一步要转的角度"。走完一圈总共转了 360°——所以外角和 = 360°。
方法二：每个内角 + 外角 = 180°。n 个内角和 = n × 180° - 外角和 = (n-2) × 180°。所以外角和 = n × 180° - (n-2) × 180° = 360°。✓

举个例子：
- 三角形：每个内角 60°，每个外角 120°。3 个外角 = 360°。✓
- 正方形：每个内角 90°，每个外角 90°。4 个外角 = 360°。✓
- 五边形：每个内角 108°，每个外角 72°。5 个外角 = 360°。✓
- 六边形：每个内角 120°，每个外角 60°。6 个外角 = 360°。✓
- n 边形：每个内角 (n-2) × 180°/n，每个外角 180°/n。n 个外角 = 180°。等等，不对，让我重算。

外角 = 180° - 内角 = 180° - (n-2) × 180°/n = (180n - 180n + 360)/n = 360°/n。
n 个外角 = n × 360°/n = 360°。✓

外角和 = 360° 的应用：
- 测量：可以走一圈来测量多边形
- 机器人：自动转向一圈
- 建筑：转角设计
- 设计：每转 360° 走完整路径

这个定理还在 GPS 路径规划、计算机图形学、机器人学里广泛应用。

凸多边形外角和恒等于 360°。但凹多边形（有一个内角大于 180°）外角和有正有负，代数和仍然是 360°。
