同学们好！今天我们来看五角星里的黄金比例。

什么是五角星？把一个正五边形的 5 个顶点用对角线连起来，形成的 5 角星。

五角星里有非常多黄金比例。让我们仔细看：

第一条：对角线与边的比是 φ。具体地，正五边形对角线长 / 边长 = φ ≈ 1.618。

第二条：五角星里更小的对角线与边的比也是 φ。无限递归——五角星是"自相似"分形。

第三条：五角星每个顶角都是 36°。5 个 36° 顶角拼成 180°，所以 5 角星里 5 个尖端能围成半圆。

第四条：五角星里的"三角形尖"是黄金三角形（底角 72°、顶角 36°）。每个黄金三角形的腰与底之比 = φ。

第五条：五角星每个"内凹角"是 108°（180° - 36° - 36°）。

五角星里黄金比例的具体数字：
设正五边形边长 = 1。
对角线长 = φ ≈ 1.618。
五角星的外接圆半径 = φ²/2 ≈ 1.309。

更细的：
对角线长 = (1 + √5)/2 = φ
对角线还把对角线分成 φ:1 = φ²:φ 这样的比例。

数学证明：解方程 x² = x + 1，得 x = (1 + √5)/2 = φ。

五角星的历史和文化：
- 毕达哥拉斯学派的标志
- 多个国家的国旗（如美国、星条旗）
- 基督教、犹太教、印度教的符号
- 美学：被认为"最美的几何图形"之一

数学中的五角星：
- 5 个黄金三角形组成
- 跟 φ、斐波那契数列深度相关
- 在正多面体（十二面体、二十面体）里出现
- 群论里 D₅ 对称群

达·芬奇的维特鲁威人（人体黄金比例）、富勒的测地线穹顶（基于二十面体）都跟五角星 + 黄金比例有关。
