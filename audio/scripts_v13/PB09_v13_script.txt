同学们好！今天我们来看一个超深刻的概率悖论——Bertrand 悖论。

Bertrand 在 1889 年提出："在一个圆内随机画一条弦，弦长大于 √3 半径的概率是多少？"

答案是 1/2、1/3 还是 1/4？——都对！因为"随机"可以多种定义。

方法一（端点随机）：两个端点随机落在圆周上。弦长 > √3 半径（也就是内接等边三角形边长）的概率 = 1/3。

方法二（径向随机）：固定一个方向，从中点沿径向随机取点。弦长 > √3 半径的概率 = 1/2。

方法三（中点随机）：弦的中点随机落在圆内。弦长 > √3 半径（也就是中点落在内接等边三角形外接圆内）的概率 = 1/4。

三种方法都是"随机画弦"，但答案分别是 1/3、1/2、1/4。这就是 Bertrand 悖论。

为什么？因为"随机"在数学里需要严格定义。三种方法各有不同的概率空间，对应不同的"随机"。

Bertrand 悖论的意义：揭示概率论需要"明确定义样本空间和概率测度"，不能含糊地说"随机"。

具体分析：
方法一端点：A、B 都在 [0, 2π) 上均匀分布。弦长 = 2R sin(α/2)，其中 α = |A - B|。α 在 [0, 2π) 均匀分布？实际是 α 在 [0, π] 均匀（对称）。P(α > π/3) = 2/3？让我重算。

实际上方法一：两端点均匀独立。固定 A，弦长 = 2R sin(|B - A|/2)。B - A 在 [0, 2π) 均匀。P(|B - A|/2 > π/3) = P(|B - A| > 2π/3) = 2/3？再考虑 A 在前 B 在后或反后 = 1/3。OK 是 1/3。

方法二：固定径向方向 d（角位置），中点沿径向均匀。从中心到圆周，弦长 = 2√(R² - d²)。要求 > √3 R，即 2√(R² - d²) > √3 R，即 d < R/2。d 沿径向从 -R 到 R 均匀，P(|d| < R/2) = 1/2。

方法三：中点 (x, y) 在圆内均匀。圆面积 πR²。等边三角形内接圆半径 R/2。P(中点在外接圆内) = π(R/2)² / πR² = 1/4。

Bertrand 悖论给我们的启示：概率问题的答案依赖于"随机"的具体定义。

应用：算法公平性、统计采样、机器学习——都需要精确的概率定义。

现在请同学们自己动手：点"Bertrand 悖论"，看三种方法（端点、径向、中点）。看三种方法给出的不同答案（1/3、1/2、1/4）。想想为什么"随机画弦"会有不同答案。明天带过来我们比一比。

记住：数学不只藏在书本里——藏在每一个"随机"都需要精确定义的有趣哲学里。

最后总结，这 Bertrand 悖论（圆内随机弦） 我们讲了 5 步：Bertrand 悖论：三种"随机" → 模拟 3 种方法 → 三种概率对比 → 哲学：概率需要定义 → Bertrand 悖论小史。
