同学们好！今天我们来看一个超美的几何公式——多边形内角和。

什么是多边形？3 条边以上就是多边形——3 边叫三角形，4 边叫四边形，5 边叫五边形...

每个多边形的内角加起来是多少？

三角形内角和 = 180°。这是欧几里得在 2000 多年前证明的。
四边形内角和 = 360°。
五边形内角和 = 540°。
六边形内角和 = 720°。
七边形内角和 = 900°。
八边形内角和 = 1080°。

发现规律了吗？内角和等于 (n-2) 乘 180°！n 边形内角和 = (n-2) × 180°。

为什么是 (n-2) 乘 180°？因为一个 n 边形可以从一个顶点画对角线，分成 (n-2) 个三角形！每个三角形内角和 180°，所以 n 边形内角和 = (n-2) × 180°。

举个例子：5 边形（n=5）。从一个顶点画对角线，可以分成 3 个三角形（5-2=3）。所以内角和 = 3 × 180° = 540°。✓

这有什么用？
- 验证：你可以用尺子量每个内角，加起来看是不是 180°(n-2)
- 计算：知道内角和反推某个内角（比如正多边形）
- 设计：建筑、平面设计、艺术创作

具体应用：
- 三角板：60°、60°、60° 三角形
- 砖块：矩形（90°、90°、90°、90°，内角和 360°）
- 蜂巢：六边形（每个内角 120°，6 个内角 720°）
- 足球：12 个五边形 + 20 个六边形（截顶二十面体）

正多边形每个内角相等，所以 n 边形正多边形每个内角 = (n-2) × 180° / n。
- 等边三角形：60°
- 正方形：90°
- 正五边形：108°
- 正六边形：120°
- 正七边形：约 128.57°
- 正八边形：135°

记住：数学不只藏在书本里——藏在每一个"几边形内角之和"的有趣几何里。

最后总结，这 多边形内角和 我们讲了 5 步：多边形内角和 = (n-2) × 180° → 验算内角和 → SVG 多边形 + 对角线划分 → 增长曲线 (n vs 内角和) → 欧几里得与多边形内角和。
