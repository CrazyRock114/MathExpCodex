同学们好！今天我们来看一个超基础的算法——二分搜索（Binary Search）。

二分搜索：在有序数组中找目标值。每次比较中点，缩小一半范围。

算法步骤：
1. left = 0, right = n-1
2. 当 left ≤ right：
   - mid = (left + right) / 2
   - 如果 arr[mid] == target：返回 mid
   - 如果 arr[mid] < target：left = mid + 1
   - 如果 arr[mid] > target：right = mid - 1
3. 未找到

时间复杂度：O(log n)

举例：在 [1, 3, 5, 7, 9, 11, 13, 15] 找 11
- mid = (0+7)/2 = 3，arr[3] = 7 < 11，left = 4
- mid = (4+7)/2 = 5，arr[5] = 11 == 11，返回 5
- 2 步找到！

如果在 [1, 3, 5, 7, 9, 11, 13, 15] 找 6
- mid = 3, arr[3] = 7 > 6, right = 2
- mid = (0+2)/2 = 1, arr[1] = 3 < 6, left = 2
- mid = 2, arr[2] = 5 < 6, left = 3
- left > right，未找到
- 3 步确定不存在

二分搜索要求数组有序。

二分搜索的应用：
第一条：字典查单词
第二条：电话簿查号码
第三条：数据库索引（B 树本质是二分搜索的扩展）
第四条：二分查找 bug 版本
第五条：求平方根
第六条：旋转数组中搜索
第七条：找峰值

二分搜索的变种：
第一条：找第一个 ≥ target 的位置
第二条：找最后一个 ≤ target 的位置
第三条：找第一个 > target 的位置
第四条：找第一个 == target 的位置（多个匹配时）
第五条：找峰值（局部最大）

这些变种都基于"left = mid + 1"或"right = mid - 1"的边界处理。

二分搜索的边界陷阱：
- mid = (left + right) / 2 在 left + right 很大时可能溢出
- 改用 mid = left + (right - left) / 2
- 或 mid = (left + right) >>> 1（位运算）

举例：在 4 亿个数字里找某个数。
- 顺序搜索：最坏 4 亿次比较
- 二分搜索：最坏 32 次比较（因为 2³² ≈ 43 亿）

加速 1200 万倍！

实际应用：Python `bisect` 模块、C++ `lower_bound` / `upper_bound`、Java `Arrays.binarySearch` 都是二分搜索。

二分搜索的"近亲"：
- 跳表：O(log n) 链表搜索
- AVL 树：自平衡二叉搜索树
- 红黑树：另一种自平衡
- B 树：磁盘友好的多路搜索
