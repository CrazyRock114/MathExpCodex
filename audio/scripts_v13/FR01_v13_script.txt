同学们好！今天我们来看一个超美的分形——曼德博集合（Mandelbrot Set）。

什么是曼德博集合？在复平面上，所有"迭代不发散"的复数 c 构成的集合。

迭代公式：z₀ = 0, z_{n+1} = zₙ² + c

判定方法：迭代最多 1000 步，如果 |z| 一直小于 2，就认为 c 在集合内；否则在集合外。

曼德博集合由数学家 Benoit Mandelbrot 在 1980 年发现。它是数学史上最复杂的对象之一——分形几何的标志。

曼德博集合的形状：
- 主心形：中心 (-0.5, 0) 附近
- 周围环绕着大大小小的"小球"——这些是分形
- 放大看，每个小球还有更小的球
- 无限细节、自相似

具体地说，曼德博集合位于复平面上：
- 中心：c = 0（z = 0 → 0² + 0 = 0，永远不逃逸）
- 主心形：-1 ≤ Re(c) ≤ 0.25
- 圆盘：|c| ≤ 1/4 内的点都在集合内
- 边界：极端复杂（无限细节）

举例：
- c = 0：|z| 永远 0，在集合内
- c = 1：z = 0, 1, 2, 5, 26, ...，很快逃逸，不在集合内
- c = -1：z = 0, -1, 0, -1, 0, ... 振荡，在集合内
- c = -2：z = 0, -2, 2, 2, 6, ...，逃逸，不在集合内
- c = -0.5 + 0.5i：z 复杂振荡，在集合内
- c = 0.25 + 0i：边界点（数学上属于"主心形"）

曼德博集合的渲染：
- 集合内：黑色
- 集合外：根据逃逸速度染色（迭代次数 → 颜色）

无限细节：放大曼德博集合的边界，每次放大都看到新的结构——像分形海马、分形螺旋、分形花朵。

数学性质：
- 连通：单连通区域（朱利亚定理）
- 边界：无限复杂（不是分形线段，是分形曲线）
- 面积：有限但精确值未知（介于 1.50 和 1.57 之间）

应用：
- 复分析
- 动力系统
- 混沌理论
- 计算机图形学

计算机画曼德博：1000 步迭代、屏幕每个像素是一个 c，循环看是否逃逸。

计算复杂度：每个像素 1000 步，10 万像素 = 1 亿步。所以渲染慢。

加速：用 SIMD 指令、GPU 并行。

记住：数学不只藏在书本里——藏在每一个"迭代到发散"的有趣无限细节里。

最后总结，这 曼德博集合 我们讲了 5 步：曼德博集合 — z² + c 迭代 → 验算: 输入 c 看迭代 → 大范围扫描: canvas 画集合 → 进阶: 边界放大细节 → 曼德博集合小史。
